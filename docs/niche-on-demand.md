# On-demand exploration deferred

The product decision on 2026-10-06 is database-only searching. Public research POST/status
routes, UI exploration controls and agent-manifest exploration offers are removed.
Previously queued on-demand validation is cancelled; no foreground model calls are
triggered by user lookup. Internal durable-job primitives are retained for possible
future use and are not registered as manager tools or public APIs.

See [current query service](niche-query-service.md) for three daily free human searches,
$9.99/month human subscription, per-call agent pricing, private query-topic logging,
background query inspirations, broader source adapters and real WebSub subscriptions.
