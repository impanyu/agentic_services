01 / Our two A4As

Our two A4As connect two complementary goals: agents that run applications, and applications that serve agents.

01 / AI agent-native applications

Agent for App

We believe apps can serve people better with agents at their core. Agents understand people’s goals, adapt to changing needs, and help turn intentions into results.

We build AI agent-native apps: the agent plans actions, chooses tools, and directs the workflow. Software provides the interfaces, tools, and execution boundaries that let the agent act reliably.

  • Agent-led control
  • Adaptive workflows
  • Goal-driven experiences

02 / Infrastructure for the agent era

App for Agent

We believe AI agents will become the primary users of applications. They will discover services, use tools, access data, and complete work on people’s behalf.

We build infrastructure for that future: applications and services agents can discover, understand, and call. Clear interfaces and reliable execution help agents research, create, transact, and complete tasks.
