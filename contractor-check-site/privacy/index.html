Privacy

We store the license number you submit, the CSLB report we generate, its Checkout session ID, and an order reference so we can deliver your purchase. We remove the stored license number and report after 30 days; the report link then stops working. We retain a hashed request reference and basic payment ledger data for accounting and fraud review.

Stripe processes card payments. Our service checks payment status with Stripe; it does not receive or store your card number. Your submitted license number is sent to the public CSLB website to retrieve its record. We do not sell report data.

Your report link contains a hard-to-guess Checkout session ID. Anyone with that link may be able to view the report during its access period, so keep it private. For a data or payment question, contact contact@aisoup.net. Last updated October 3, 2026.
